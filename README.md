## Open source

| Project | What it does |

| **[UPIlerify](https://github.com/harshavarma02/UPILerify)** | Self-hosted UPI payment verification with no gateway and no aggregator fee. Reads the bank's credit-alert email over IMAP, matches the UTR, and sends an HMAC-signed webhook in under 3 seconds. [Live site](https://upilerify.online) |
